## 一、项目概述

一个**前后端完全分离**的个人博客系统，包含博客前台展示与后台内容管理两大子系统。

**核心特点：**

- 🎯 **功能完整**：文章、分类、标签、评论、点赞、用户、统计七大模块，30 个 RESTful 接口
- 🔐 **三级权限**：访客 / 登录用户 / 管理员，用注解声明式鉴权
- 📝 **Markdown 全流程**：后台所见即所得编辑器，前台实时渲染，正文原样存库
- 💾 **数据持久化**：MySQL 8 + MyBatis-Plus，重启数据不丢
- 🚀 **开箱即用**：不需要 Redis / MQ / 注册中心等任何中间件
- 📖 **中文注释**：核心代码逐行注释，适合作为学习/教学项目

**代码规模：**

| 部分 | 文件数 | 代码行数 |
|---|---|---|
| 后端 Java | 69 | 约 4,200 行 |
| 前端 Vue/JS | 33 | 约 7,250 行 |
| SQL 脚本 | 2 | 约 500 行 |
| 文档 | 3 | — |

**后端分层：**

| 层 | 包 | 职责 |
|---|---|---|
| 控制器层 | `controller` | 接收请求、参数绑定、权限注解、统一响应包装 |
| 业务层 | `service` / `service.impl` | 业务规则、事务控制、VO 组装（等价于 JOIN） |
| 持久层 | `mapper` | MyBatis-Plus `BaseMapper` + 注解 SQL |

| 横切关注点 | `config` / `exception` / `util` | 鉴权、跨域、异常、JWT、密码 |

### 鉴权实现

后端用**两个自定义注解 + 一个拦截器**实现，声明与接口定义写在一起，改接口时不会忘记改规则：

```java
@PostMapping("/articles")
@RequireAdmin                 // 未登录 → 401；已登录非管理员 → 403
public Result<ArticleVO> create(@RequestBody @Valid ArticleDTO dto) { ... }
```

| 注解 | 语义 |
|---|---|
| `@RequireLogin` | 必须登录，否则 `code: 401` |
| `@RequireAdmin` | 必须是管理员（隐含必须登录），越权返回 `code: 403` |

可打在**方法**上（单接口生效）或**类**上（整个 Controller 生效），方法级优先。

**鉴权失败的表现**：HTTP 状态码恒为 `200`，业务码区分 —— 这是本项目的统一约定。

## 五、前台功能详解

### 5.1 首页（文章列表）

| 功能 | 说明 |
|---|---|
| 分页展示 | 每页 6 条，`el-pagination` 分页器，支持切换页码 |
| 文章卡片 | 封面图（16:9）、标题、简介、作者头像+昵称、发布时间、浏览量、点赞数、分类、标签 |
| 分类筛选 | 点击分类只显示该分类文章，页码自动重置为 1 |
| 标签筛选 | 点击标签筛选，与分类筛选可叠加 |
| 关键词搜索 | 匹配**标题或简介**，大小写不敏感，输入框 300ms 防抖 |
| 热门文章 | 侧栏显示浏览量 Top5 |
| 置顶排序 | 置顶文章永远排在最前 |
| 空状态 | 无数据时显示友好提示 |

**排序规则**：`置顶 DESC` → `发布时间 DESC`。

**可见性**：前台**只能看到已发布文章**，草稿完全不出现（包括搜索与分页统计）。

### 5.2 文章详情页

| 功能 | 说明 |
|---|---|
| Markdown 渲染 | `MdPreview` 渲染，支持代码块高亮、表格、引用、图片 |
| 浏览量统计 | 每次打开详情页 **+1**（用 SQL 原子自增，并发不丢数） |
| 点赞 | 未登录点击 → 提示并跳转登录；已登录 → 点赞/取消点赞**切换** |
| 评论区 | 两级树展示，顶级评论下挂回复 |
| 发表评论 | 需登录，内容 1~500 字 |
| 回复评论 | 点击「回复」自动带上 `@某某`，可取消 |
| 作者信息 | 头像、昵称、发布时间 |
| 分类 / 标签 | 可点击跳回首页并自动筛选 |
| 返回顶部 | 长文阅读体验优化 |

### 5.3 分类页

展示全部分类卡片：分类名、描述、**文章数**，点击进入首页并按该分类筛选。

### 5.4 标签页

标签云样式展示全部标签：标签名、颜色、文章数，按文章数倒序（热门靠前），点击筛选。

### 5.5 登录 / 注册

| 功能 | 说明 |
|---|---|
| 登录 | 用户名 + 密码，成功后写入 token 并跳回来源页（`redirect` 参数） |
| 注册 | 用户名（4~16 位字母/数字/下划线）、密码（6~20 位）、确认密码、昵称、邮箱；成功即自动登录 |
| 表单校验 | 前端实时校验 + 后端二次校验 |
| 错误提示 | 用户名已存在、密码错误、**账号被禁用**等均有明确提示 |
| 路由守卫 | 未登录访问需登录页面 → 跳登录页并记录回跳地址；已登录访问登录页 → 跳首页 |
| 登录态保持 | token 存 `localStorage`，刷新页面不丢失 |

> **安全细节**：用户名不存在与密码错误返回**同一句提示**「用户名或密码错误」，避免账号枚举攻击。

### 5.6 个人资料

修改昵称、头像地址、邮箱、个人简介、密码。**只提交要改的字段**，未填写的字段不会被清空。

后台入口：`/admin`，需管理员登录。

| 指标 | 说明 |

| 功能 | 说明 |
|---|---|
| 列表分页 | 每页 10 条，**含草稿** |
| 关键词搜索 | 标题 / 简介 |
| 状态筛选 | 全部 / 已发布 / 草稿 |
| 状态标识 | 草稿与已发布有明显标签区分 |
| 新增 / 编辑 | 跳转编辑页 |
| 删除 | 二次确认，**级联删除**该文章的评论、标签关联、点赞记录 |

### 6.3 文章编辑页（`/admin/article/create`、`/admin/article/edit/:id`）

| 功能 | 说明 |
|---|---|
| **Markdown 编辑器** | `MdEditor` 所见即所得，工具栏完整，支持实时预览、全屏 |
| 标题 | 必填，最长 100 字 |
| 分类 | 下拉选择 |
| 标签 | 多选，可选多个 |
| 封面图 | 填写 URL，**留空自动生成占位图**（用文章 ID 保证不重复） |
| 简介 | 选填；**留空自动截取正文前 100 字**（会去掉 Markdown 标记与代码块） |
| 置顶 | 开关 |
| **保存草稿** | `status = 0`，前台不可见 |
| **发布文章** | `status = 1`，前台立即可见 |
| 编辑回填 | 调后台专用接口，**不会污染浏览量** |

### 6.4 分类管理（`/admin/categories`）

表格展示 + 弹窗表单：分类名（唯一）、描述、排序值（越小越靠前）、文章数。

**删除保护**：分类下还有文章（含草稿）时**拒绝删除**，提示「该分类下还有 N 篇文章，请先移动或删除」。

### 6.5 标签管理（`/admin/tags`）

表格 + 弹窗表单：标签名（唯一）、颜色（颜色选择器，`#RRGGBB` 格式校验）、文章数。

**删除行为**：允许删除，同时把该标签从**所有文章**上摘除（清理中间表），不留脏数据。

### 6.6 评论管理（`/admin/comments`）

| 功能 | 说明 |
|---|---|
| 分页列表 | 每页 10 条，倒序 |
| 关键词搜索 | 匹配**评论内容**或**评论人昵称** |
| 显示文章标题 | 知道这条评论属于哪篇文章 |
| 删除 | 管理员可删除任意评论；删顶级评论会**连带删除其全部回复** |

### 6.7 用户管理（`/admin/users`）

| 功能 | 说明 |
|---|---|
| 分页列表 | 用户名、昵称、邮箱、角色、状态、注册时间、最近登录 |
| 关键词搜索 | 用户名 / 昵称 |
| 启用 / 禁用 | 禁用后**无法登录**，且其已签发的 token **立即全部作废**（强制下线） |
| 删除 | 连带删除该用户的评论与登录令牌 |
| 保护规则 | 不能禁用/删除**内置超管**（id=1），不能操作**自己** |

**密码永不下发**：用户列表与登录响应中都不包含 `password` 字段。

## 七、接口清单

### 7.1 通用约定

**基础路径**：`http://localhost:8082/api`

**统一响应结构：**

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": { },
  "timestamp": 1710000000000
}
```

**分页数据结构：**

```json
{
  "records": [],
  "total": 10,
  "page": 1,
  "size": 6,
  "pages": 2
}
```

**业务状态码：**

| code | 含义 | 典型场景 |
|---|---|---|
| 200 | 成功 | — |
| 400 | 参数校验失败 | 标题为空、标签颜色格式错误 |
| 401 | 未登录 / token 失效 | 未登录点赞、登出后使用旧 token |
| 403 | 权限不足 | 普通用户访问后台、删除他人评论、账号被禁用 |
| 404 | 资源不存在 | 文章/分类不存在、访问草稿详情、接口不存在 |
| 500 | 业务失败 / 系统异常 | 用户名已存在、分类下有文章不能删 |

> **HTTP 状态码恒为 200**，只看 `code` 字段。这样前端拦截器只需一套判断逻辑。

**认证方式**：请求头 `Authorization: Bearer <token>`

### 7.3 典型请求示例

**登录**

```bash
curl -X POST http://localhost:8082/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"123456"}'
```

```json
{
  "code": 200,
  "msg": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzM4NCJ9...",
    "tokenType": "Bearer",
    "expiresIn": 86400000,
    "user": { "id": 1, "username": "admin", "nickname": "超级管理员", "role": "ADMIN", "status": 1 }
  }
}
```

**分页查询文章**

```bash
curl "http://localhost:8082/api/articles?page=1&size=6&categoryId=1&keyword=Vue"
```

**发布文章（管理员）**

```bash
curl -X POST http://localhost:8082/api/articles \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \

    "tagIds": [1, 3],
    "status": 1,
    "top": 0
  }'
```

```json
{ "code": 400, "msg": "文章标题不能为空；分类不存在，id=999", "data": null }
```

## 八、数据模型

### 8.1 实体关系

```
                    ┌─────────────┐
                    │   t_user    │
                    └──────┬──────┘
           作者 1:N ┌──────┼──────┐ 1:N 评论
                   ▼      │      ▼
            ┌──────────┐  │  ┌───────────┐
            │t_article │  │  │ t_comment │
            └────┬─────┘  │  └─────┬─────┘
      分类 1:N   │        │        │ 自关联（两级）
                 ▼        │        └──► parent_id
            ┌──────────┐  │
            │t_category│  │
            └──────────┘  │
                          ▼
   t_article ◄──N:M──► t_tag          t_user ◄──N:M──► t_article
        （通过 t_article_tag）              （通过 t_article_like：点赞）

                              t_user 1:N t_user_token（登录令牌）
```

### 8.2 表结构要点

| 表 | 关键字段 | 说明 |
|---|---|---|
| `t_user` | `role` / `status` | `ADMIN`\|`USER`；`1` 正常 / `0` 禁用 |
| `t_article` | `content`(LONGTEXT) / `status` / `is_top` | Markdown 原文；`0` 草稿 / `1` 已发布 |
| `t_article_tag` | `(article_id, tag_id)` 唯一 | 多对多中间表 |
| `t_article_like` | `(article_id, user_id)` 唯一 | **数据库层面保证不重复点赞** |
| `t_comment` | `parent_id` / `reply_to_nickname` | 两级评论；昵称冗余仅为展示 |
| `t_user_token` | `token` 唯一 / `expire_at` | JWT 白名单，支持登出即失效 |

### 8.3 状态字段取值速查

| 字段 | 取值 | 含义 |
|---|---|---|
| `t_user.role` | `ADMIN` | 管理员 |
| | `USER` | 普通用户 |
| `t_user.status` | `1` | 正常 |
| | `0` | 禁用（无法登录） |
| `t_article.status` | `1` | 已发布（前台可见） |
| | `0` | 草稿（仅后台可见） |
| `t_article.is_top` | `1` | 置顶 |
| | `0` | 普通 |
| `t_comment.status` | `1` | 显示 |
| | `0` | 屏蔽 |

## 九、核心业务规则

以下是本项目实现的、值得注意的业务约束：

| # | 规则 | 实现位置 | 说明 |
|---|---|---|---|
| 1 | **草稿前台不可见** | `ArticleServiceImpl#pagePublished` | 前台查询强制 `status = 1`；直接访问草稿详情返回 404 |
| 2 | **点赞是切换语义** | `ArticleServiceImpl#toggleLike` | 同一个接口完成点赞/取消，返回最新的 `liked` 状态 |
| 3 | **点赞幂等** | `t_article_like` 唯一索引 | 即使代码有并发 Bug，数据库也不会产生重复点赞记录 |
| 4 | **两级评论扁平化** | `CommentServiceImpl#create` | 回复"回复"时自动挂到顶级评论下，不会出现三层嵌套 |
| 5 | **父评论删除后回复不消失** | `CommentServiceImpl#listByArticle` | 父评论不存在时，子回复降级为顶级评论展示 |
| 6 | **评论数一致性** | `CommentServiceImpl#delete` | 删除后**重新 COUNT** 回填，而不是简单 `-1` |
| 7 | **分类删除保护** | `CategoryServiceImpl#delete` | 分类下有文章（含草稿）时拒绝删除，防止悬空外键 |
| 8 | **标签删除清理关联** | `TagServiceImpl#delete` | 删除标签时同步清理中间表，避免出现"空标签" |
| 9 | **级联删除** | 文章/用户删除 | 删文章 → 连带评论、标签关联、点赞；删用户 → 连带评论、令牌 |
| 10 | **超管保护** | `UserServiceImpl` | 内置超管（id=1）不可被禁用或删除；管理员不能操作自己 |
| 11 | **禁用即下线** | `UserServiceImpl#updateStatus` + `JwtInterceptor` | 禁用账号时清空其所有 token；鉴权时回查用户状态，禁用立即生效 |
| 12 | **角色变更立即生效** | `JwtInterceptor#resolveLoginUser` | 每次鉴权都回查数据库，不用等 token 过期 |
| 13 | **密码永不下发** | `UserVO` | 出参对象不含 `password` 字段；实体上也有 `@JsonIgnore` 双保险 |
| 14 | **不发账号枚举提示** | `UserServiceImpl#login` | 用户名不存在与密码错误返回同一提示 |
| 15 | **摘要自动生成** | `ArticleServiceImpl#resolveSummary` | 简介留空时截取正文前 100 字，并去掉 Markdown 标记 |
| 16 | **浏览量原子自增** | `setSql("views = views + 1")` | 用 SQL 自增而非"读出来+1写回"，并发不丢更新 |

## 十、技术特性

### 10.1 统一响应与全局异常

Controller / Service **不需要写任何 try-catch**，所有异常由 `GlobalExceptionHandler` 统一翻译成标准 JSON：

| 异常类型 | 处理结果 |
|---|---|
| `BusinessException` | 按业务码返回（预期内的失败） |
| `MethodArgumentNotValidException` | 400 + 拼接所有字段错误信息 |
| `ConstraintViolationException` | 400 |
| `HttpMessageNotReadableException` | 400 请求体格式错误 |
| `MethodArgumentTypeMismatchException` | 400 参数类型错误 |
| `HttpRequestMethodNotSupportedException` | 400 不支持的方法 |
| `NoHandlerFoundException` | 404 接口不存在 |
| `Exception`（兜底） | 500 + 记录完整堆栈，对外只给模糊提示 |

### 10.2 参数校验

DTO 上用 `javax.validation` 注解声明规则，Controller 用 `@Valid` 触发：

```java
@NotBlank(message = "文章标题不能为空")
@Size(max = 100, message = "标题最长 100 个字符")
private String title;

@Pattern(regexp = "^#[0-9a-fA-F]{6}$", message = "标签颜色必须是 #RRGGBB 格式")
private String color;
```

### 10.3 JWT 认证

| 特性 | 实现 |
|---|---|
| 算法 | HS256（对称加密） |
| 密钥 | 配置文件，≥32 字节（否则 jjwt 抛 `WeakKeyException`） |
| 有效期 | 默认 24 小时，可配置 |
| 白名单 | 落库 `t_user_token`，**登出立即失效**、**重启不掉线** |
| 惰性清理 | 鉴权时顺带删除过期 token，无需定时任务 |
| 权限注解 | `@RequireLogin` / `@RequireAdmin` |
| 上下文 | `ThreadLocal` 存放当前用户，请求结束**必须清理**（防线程复用越权） |

### 10.4 性能优化

| 优化点 | 做法 | 效果 |
|---|---|---|
| **防 N+1 查询** | 收集 ID → 批量 `IN` → 内存拼装 | 一页 10 篇文章固定 5 次查询，而非 40 次 |
| **排除大字段** | 列表查询 `.select(排除 content)` | 不把几十 KB 的 Markdown 拉进内存 |
| **覆盖索引** | `idx_status_top_create` | 前台列表查询走索引 |
| **分组统计** | `GROUP BY` 一次查出所有分类/标签计数 | 避免逐个 `COUNT` |
| **物理分页** | MyBatis-Plus `PaginationInnerInterceptor` | 生成 `LIMIT`，不是内存分页 |
| **前端分包** | Vite `manualChunks` | vue / element-plus / md-editor 分包，利于长期缓存 |
| **前端防抖** | 搜索框 300ms | 减少无效请求 |
| **连接池** | HikariCP | 默认配置，最大 10 连接 |

### 10.5 前端工程化

| 特性 | 实现 |
|---|---|
| 组件风格 | 全部 `<script setup>` 组合式 API，无 Options API |
| 请求封装 | Axios 拦截器：自动注入 token、统一错误提示、401 自动跳登录 |
| 并发 401 防护 | `redirecting` 开关，避免多个请求同时 401 导致重复跳转 |
| 路由懒加载 | `() => import(...)`，按页面分包 |
| 路由守卫 | 登录校验 + 管理员校验 + 已登录用户拦截登录页 |
| 登录态 | `reactive` store + `localStorage`（不使用 Pinia，保持技术栈精简） |
| 图片兜底 | `@error` 时替换占位图，不出现破图 |
| 响应式布局 | CSS Grid / flex-wrap，移动端至少不塌 |

## 十四、已知限制与规划

### 14.1 当前限制（请知悉）

| # | 限制 | 说明 |
|---|---|---|
| 1 | **无文件上传** | 封面与头像使用**外链 URL**，不支持本地上传。离线环境图片加载不出来（有兜底） |
| 2 | **密码用 MD5** | 仅为演示"不存明文"，**生产必须换 BCrypt** |
| 3 | **无 refresh token** | token 过期后需重新登录（有效期 24 小时） |
| 4 | **搜索是 LIKE 模糊匹配** | 不支持分词、相关性排序、全文索引 |
| 5 | **无单元测试** | 只有端到端脚本（Python），没有 JUnit 测试用例 |
| 6 | **无 Docker 编排** | 按需求未提供 Dockerfile / docker-compose |
| 7 | **`t_user_token` 会增长** | 每次登录插一条；生产建议改 Redis（带 TTL） |
| 8 | **无审计日志** | 后台操作没有留痕 |
| 9 | **无富文本评论** | 评论是纯文本（防止 XSS），不支持表情/图片 |
| 10 | **单机部署** | 令牌白名单与统计都在单库，未做分布式适配 |

### 14.2 后续规划（Roadmap）

- [ ] 密码摘要升级为 BCrypt + 加盐

- [ ] 全文检索（Elasticsearch 或 MySQL 全文索引）

### 14.3 二次开发指引

| 想做什么 | 改哪里 |
|---|---|
| 加一个字段 | ① `01-schema.sql` 加列 → ② 实体加属性 → ③ DTO/VO 加字段 → ④ 前端表单 |
